# Closed TARGET_PROJECT Requests

Store settled ECRs here. Keep `Source lifecycle: Closed` and record the
disposition, date, rationale, and source closure authority. Include an
authoritative target reference whenever the record claims a target
acknowledgement or disposition.

Closed does not mean accepted or implemented. Preserve rejected, deferred,
duplicate, superseded, withdrawn, and no-change-required outcomes. Reopen
through an append-only event without erasing the earlier closure.
