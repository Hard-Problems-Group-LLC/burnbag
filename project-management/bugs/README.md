# Bug Records

Use the summary files in this directory as concise priority indexes. Each
entry should contain a stable ID, priority or closure date, and a link to the
authoritative detailed record in the status directory that matches its state:

- `open/`
- `in-progress/`
- `closed/`

Do not copy full lifecycle narratives into the indexes. Detailed records
contain the symptom, impact, reproduction or evidence, owner, timestamps,
root cause, resolution, and validation evidence.
