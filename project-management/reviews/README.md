# Review Records

Store structured review evidence here when project policy or the operator
requires a formal review.

- `packets/` contains the frozen material supplied to reviewers.
- `findings/` contains raw, independently attributable findings.
- `decisions/` contains adjudication, resolution, and operator decisions.

FieldManual's risk-triggered expert review board remains a proposal until the
project explicitly adopts it. These directories are neutral record
scaffolding and do not themselves require a particular board or approval
process.
